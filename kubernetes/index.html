    Practice commands

    Run these on the Linux host. They use the lab's own kubeconfig inside the K3s container.

    docker compose -f kubernetes.yml exec k3s kubectl get all -n landscape-lab
docker compose -f kubernetes.yml exec k3s kubectl get hpa -n landscape-lab -w
docker compose -f kubernetes.yml exec k3s kubectl describe statefulset database -n landscape-lab
docker compose -f kubernetes.yml exec k3s kubectl get pvc,pv -n landscape-lab
docker compose -f kubernetes.yml exec k3s kubectl rollout status statefulset/api -n landscape-lab
docker compose -f kubernetes.yml exec k3s kubectl scale statefulset/traffic -n landscape-lab --replicas=2
docker compose -f kubernetes.yml exec k3s kubectl delete pod database-0 -n landscape-lab
